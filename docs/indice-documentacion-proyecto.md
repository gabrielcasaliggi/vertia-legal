## Orden recomendado para nuevos operadores Vertia

1. Leer `manual-usuario-vertia-legal.md`.
2. Revisar `dossier-producto-vertia-legal.md` para entender el alcance completo.
3. Leer `saas-multiorg-operacion.md`.
4. Seguir `onboarding-nueva-organizacion.md` para crear un estudio cliente.
5. Validar producción con `vercel-production-checklist.md`.
6. Usar `incident-runbook.md` ante errores operativos.
